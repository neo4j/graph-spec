= Nodes
:description: The fields of a node and its labels in a Neo4j Ontology Graph Specification model document.
// The tables mirror ontology-graph-spec.schema.json, until they are generated from it

A node describes a kind of entity in the domain. Nodes are listed under `nodes`, keyed by node id.

[source,yaml]
----
nodes:
  person:
    label: Person
    description: A person who acts in or directs movies.
    aliases: [Actor, Director]
    properties:
      name:
        type: STRING
        must_exist: true
----

== Node

A node of the graph.

[cols="2,2,1,5"]
|===
| Field | Type | Required | Description

| `label` | string | No | Shorthand for the identifying label. Expanded into labels when the model is decoded.
| `labels` | <<_labels,labels>> | No | Labels of the node.
| `properties` | map of xref:reference/properties.adoc#_property[property] | No | Properties of the node keyed by id.
| `constraints` | map of xref:reference/constraints-and-indexes.adoc#_node_constraint[node constraint] | No |
Constraints on the node keyed by id.
| `extensions` | xref:reference/extensions.adoc#_node_extensions[node extensions] | No | Extensions for the node.
| `description` | string | No | Description of the node.
| `aliases` | list of strings | No | Alternative names for the node.
| `reference` | string | No | Reference or URI of an external resource describing the node.
|===

== Labels

The labels of a node.

[cols="2,2,1,5"]
|===
| Field | Type | Required | Description

| `identifier` | string | No | The label which identifies the node.
| `implied` | list of strings | No | Labels implied by the node in addition to the identifier.
| `optional` | list of strings | No | Labels which may be present on the node but aren't required.
| `extensions` | xref:reference/extensions.adoc#_custom_data[custom data] | No | Extensions for the labels.
|===
