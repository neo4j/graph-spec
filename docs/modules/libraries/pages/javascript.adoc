= JavaScript and TypeScript
:description: Use the Neo4j Ontology Graph Specification library from JavaScript and TypeScript.

The package is an ES module with TypeScript definitions.

== Install

[source,shell,subs="attributes+"]
----
npm install @neo4j/ontology-graph-spec@{library-version}
----

== Read and write models

`GraphSpec.Json` and `GraphSpec.Yaml` read and write models. Reading expands any xref:format:shorthand.adoc[shorthand].

[source,typescript]
----
import { GraphSpec } from "@neo4j/ontology-graph-spec";

const model = GraphSpec.Yaml.decodeFromString(yaml);
const json = GraphSpec.Json.encodeToString(model);
----

Lists and maps in the model are Kotlin collections. Convert them with `asJsReadonlyArrayView()` and
`asJsReadonlyMapView()`, for example `model.nodes.asJsReadonlyMapView()`.

== Validate models

[source,typescript]
----
import { GraphModel, Validations } from "@neo4j/ontology-graph-spec";

const issues = GraphModel.validate(model, Validations.core).asJsReadonlyArrayView();
----

See xref:validation.adoc[] for the validator sets and issues.

== Migrate models

To read from or write to another format, pass its type, and for writing its version.

[source,typescript]
----
const model = GraphSpec.Json.decodeFromString(dataModelJson, "data_model");
const exported = GraphSpec.Json.encodeToString(model, "data_model", "3.0.0");
----

See xref:migration.adoc[] for the supported types and versions.
