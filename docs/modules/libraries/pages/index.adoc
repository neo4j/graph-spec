= Libraries
:description: Libraries for reading, writing, validating and migrating Neo4j Ontology Graph Specification models on the JVM, in JavaScript and TypeScript, and in Go.

The libraries read, write, validate and migrate models, for tools that work with the xref:format:concepts.adoc[format]:

* xref:jvm.adoc[] for Kotlin, Java and other JVM languages
* xref:javascript.adoc[]
* xref:go.adoc[]

All three are built from the same Kotlin code, so validation and migration behave the same on every platform. To try
one, see xref:getting-started.adoc[].
